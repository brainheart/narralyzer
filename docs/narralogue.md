# Narralogue: the practice behind the tool

**[Listen to Everyday Systems Podcast episode 106 — Narralogue](https://podcast.everydaysystems.com/episode/106/)**

Reinhard introduces Narralogue and explains why regular, self-directed speaking belongs in a language-learning routine. The episode page has both audio and a transcript.

Set a timer for a manageable daily session (Reinhard uses ten minutes), speak aloud in your target language, and describe what you notice around you. Keep speaking; when a word is missing, try to explain around it in the target language. Save lookups and follow-up study for afterward.

Narralyzer is an optional companion: record an occasional session, examine the feedback, and choose useful sentences to practice. The habit itself needs only a timer.
